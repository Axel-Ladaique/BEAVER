# P1 — Nervures : implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal :** `aerorib run aile.step` oriente la pièce, génère les nervures en losange (coupées en deux par la bande de séparation), relie longerons et passages existants à la peau par des fentes, découpe la peau, vérifie le résultat avec le validateur et exporte STEP + STL + rapport HTML.

**Architecture :** nouveaux modules `orient`, `midsurface`, `features/bores`, `features/ribs`, `pipeline`, `export` ; le validateur P0 devient fidèle au slicer (fermeture des fentes < seuil avant le contrôle de connexité), parallèle, et le maillage passe par OpenCascade natif. Repère canonique après orientation : **Z envergure (emplanture en z = 0), X corde, Y épaisseur, extrados vers +Y**.

**Tech Stack :** inchangée (Python ≥ 3.12, build123d/OCP, trimesh, shapely 2, scipy, pydantic, typer, pytest, uv).

**Spec :** `docs/specs/2026-10-09-aerorib-design.md` (§2, §7, §8, §10, §13) **et** `docs/specs/2026-10-10-p1-addendum.md` (décisions P1 — à lire en entier).

**Fixture réelle :** `tests/fixtures/fusion_aile_4412_simple_sbar.step` (Fusion 360) : envergure selon X (−210 → 0), corde selon Y, corps `WING_1` (déjà percé Ø14 pour le longeron + 4 alésages Ø2,4 sur toute l'envergure) et `SBAR_14mm_1` (Ø14, axe X, 210 mm). Le prototype de cette nuit a donné : 130 plaques, coupe valide en ~2 min, **0 défaut sur 1050 couches** avec le validateur v2.

## Global Constraints

- Python `>=3.12`, Windows **et** macOS. Tout code lancé en sous-processus (multiprocessing « spawn ») doit vivre dans un module importable ; tout point d'entrée exécutable doit être protégé par `if __name__ == "__main__":`.
- Unités : mm. Messages utilisateur en français ; identifiants en anglais.
- Repère canonique après orientation : **Z = axe de construction (emplanture z = 0), X = corde, Y = épaisseur, extrados +Y**.
- Défauts (spec §10, addendum) : `slit_width` 0.1 ; `split.gap` 0.6 ; `split.min_rib_depth` 1.0 ; motif `diamond`, `spacing` 30, `angle` = min(45, `max_overhang_deg` du preset) ; longerons `clearance` 0.15, `sleeve` 0.5, `strip` 2.0, `slit_side` top ; passages `mode` auto, `sleeve` 0.5, `strip` 1.0, `slit_side` top, `max_tilt_deg` 5 ; `validation.tessellation_tol` **0.02**.
- Critère bloquant (spec §2, §8, addendum §5) : après **fermeture morphologique de rayon `min_slit_width/2`** (simulation du slicer), chaque couche = exactement 1 polygone sans trou. Les fentes plus étroites que `min_slit_width` sont des **avertissements**.
- Tests lents (> ~20 s) marqués `@pytest.mark.slow`.
- Ne jamais affaiblir un test pour le faire passer ; une valeur attendue ne change que si on montre qu'elle était fausse.

class OrientationAxis(_Strict):
    axis: tuple[float, float, float]

    @field_validator("axis")
    @classmethod
    def _non_zero(cls, v: tuple[float, float, float]) -> tuple[float, float, float]:
        if sum(c * c for c in v) < 1e-12:
            raise ValueError("axe d'orientation nul")
        return v


class SplitSettings(_Strict):
    gap: float = Field(default=0.6, gt=0)  # largeur de la bande de séparation (mm)
    min_rib_depth: float = Field(default=1.0, ge=0)  # nervure plus courte → non coupée (bords d'attaque/fuite)
    grid: tuple[int, int] = (101, 22)  # résolution (nx, nz) de la surface médiane


class RibLayer(_Strict):
    name: str = "principal"
    pattern: Literal["diamond"] = "diamond"
    angle: float | None = Field(default=None, gt=0, lt=90)  # None → min(45, max_overhang_deg du preset)
    spacing: float = Field(default=30.0, gt=0)
    depth: Literal["full"] | float = "full"
    phase: float = 0.0
    samples: int = Field(default=16, ge=4)

    @field_validator("depth")
    @classmethod
    def _full_only(cls, v):
        if v != "full":
            raise ValueError("profondeur partielle des nervures prévue en phase P3 (utiliser depth: full)")
        return v


class BoreSettings(_Strict):
    clearance: float = Field(default=0.15, ge=0)  # jeu radial autour du longeron
    sleeve: float = Field(default=0.5, ge=0)  # matière gardée autour du trou, sans nervure
    strip: float = Field(default=2.0, gt=0)  # largeur de la bande sans nervure jusqu'à la peau
    slit_side: Literal["top", "bottom"] = "top"  # top = extrados (+Y)


class PassageSettings(_Strict):
    mode: Literal["auto", "off"] = "auto"
    sleeve: float = Field(default=0.5, ge=0)
    strip: float = Field(default=1.0, gt=0)
    slit_side: Literal["top", "bottom"] = "top"
    max_tilt_deg: float = Field(default=5.0, gt=0, lt=90)


class OutputSettings(_Strict):
    dir: str = "out"
    formats: list[Literal["step", "stl"]] = ["step", "stl"]

    @model_validator(mode="after")
    def _valid_p1(self) -> "Config":
        limit = self.preset.max_overhang_deg
        for layer in self.rib_layers:
            if self.rib_angle(layer) > limit:
                raise ValueError(
                    f"rib_layers '{layer.name}' : angle {self.rib_angle(layer)}° > surplomb max {limit}° du preset"
                )
        for name in self.spars:
            try:
                self.spar_settings(name)
            except ValidationError as exc:
                raise ValueError(f"spars '{name}' invalide : {exc}") from exc
        return self

    def rib_angle(self, layer: RibLayer) -> float:
        return layer.angle if layer.angle is not None else min(45.0, self.preset.max_overhang_deg)

    def spar_settings(self, name: str) -> BoreSettings:
        base = self.spars.get("default", {})
        override = next(
            (v for k, v in self.spars.items() if k != "default" and k.lower() == name.lower()), {}
        )
        return BoreSettings.model_validate({**base, **override})
```

from OCP.BRepMesh import BRepMesh_IncrementalMesh
from OCP.StlAPI import StlAPI_Writer


def to_mesh(shape: Shape, tol: float = 0.02, angular: float = 0.3) -> trimesh.Trimesh:
    """Maillage OpenCascade natif (parallèle), relu via un STL binaire temporaire."""
    BRepMesh_IncrementalMesh(shape.wrapped, tol, False, angular, True)
    fd, tmp = tempfile.mkstemp(suffix=".stl")

    try:
        writer = StlAPI_Writer()
        if hasattr(writer, "ASCIIMode"):
            writer.ASCIIMode = False

        return trimesh.load(tmp, file_type="stl", force="mesh")
    finally:
        os.remove(tmp)

from concurrent.futures import ProcessPoolExecutor
from dataclasses import dataclass, field

PARALLEL_MIN_LAYERS = 64


def slicer_closing(polygons, min_width: float) -> tuple[Polygon, ...]:
    """Ce que le slicer imprime : les fentes plus étroites que min_width sont refermées."""
    r = min_width / 2
    out: list[Polygon] = []
    for poly in polygons:
        closed = poly.buffer(r, join_style="mitre").buffer(-r, join_style="mitre")
        out.extend(p for p in _parts(closed) if isinstance(p, Polygon))
    return tuple(out)
```

"""Surface médiane y_mid(x, z) d'une pièce orientée (addendum P1 §2)."""

from __future__ import annotations

from dataclasses import dataclass

import numpy as np
from build123d import Solid
from scipy.interpolate import RegularGridInterpolator
from shapely.geometry import LineString, Polygon
from shapely.ops import unary_union

from aerorib.slicing import slice_layers


def mid_line(envelope, xs: np.ndarray, y_lo: float, y_hi: float) -> tuple[np.ndarray, np.ndarray]:
    ymid = np.full(len(xs), np.nan)
    thick = np.zeros(len(xs))
    for i, x in enumerate(xs):
        cut = envelope.intersection(LineString([(x, y_lo), (x, y_hi)]))
        if cut.is_empty:
            continue
        y0, y1 = cut.bounds[1], cut.bounds[3]
        ymid[i] = (y0 + y1) / 2
        thick[i] = y1 - y0
    return ymid, thick


def camber_offset(section: Polygon, n: int = 41) -> float:
    env = Polygon(section.exterior)
    coords = np.asarray(env.exterior.coords)
    le, te = coords[np.argmin(coords[:, 0])], coords[np.argmax(coords[:, 0])]
    xs = np.linspace(le[0], te[0], n + 2)[1:-1]
    x0, y0, x1, y1 = env.bounds
    ymid, _ = mid_line(env, xs, y0 - 1, y1 + 1)
    chord_y = le[1] + (te[1] - le[1]) * (xs - le[0]) / (te[0] - le[0])
    return float(np.nanmean(ymid - chord_y))


@dataclass(frozen=True)
class MidSurface:
    xs: np.ndarray
    zs: np.ndarray
    ymid: np.ndarray  # (nx, nz)
    thick: np.ndarray  # (nx, nz)

    @classmethod
    def from_skin(cls, skin: Solid, nx: int = 101, nz: int = 22, tol: float = 0.02) -> "MidSurface":
        bb = skin.bounding_box()
        xs = np.linspace(bb.min.X, bb.max.X, nx)
        zs = np.linspace(bb.min.Z + 0.3, bb.max.Z - 0.3, nz)
        ymid = np.full((nx, nz), np.nan)
        thick = np.zeros((nx, nz))
        for j, layer in enumerate(slice_layers(skin, zs, tol)):
            if not layer.polygons:
                continue
            env = unary_union([Polygon(p.exterior) for p in layer.polygons])
            ymid[:, j], thick[:, j] = mid_line(env, xs, bb.min.Y - 5, bb.max.Y + 5)
        for j in range(nz):
            ok = ~np.isnan(ymid[:, j])
            ymid[:, j] = np.interp(xs, xs[ok], ymid[ok, j]) if ok.any() else 0.0
        return cls(xs, zs, ymid, thick)

    def at(self, x: np.ndarray, z: np.ndarray) -> tuple[np.ndarray, np.ndarray]:
        x = np.asarray(x, dtype=float)
        z = np.asarray(z, dtype=float)
        pts = np.column_stack([np.clip(x, self.xs[0], self.xs[-1]), np.clip(z, self.zs[0], self.zs[-1])])
        ym = RegularGridInterpolator((self.xs, self.zs), self.ymid)(pts)
        th = RegularGridInterpolator((self.xs, self.zs), self.thick)(pts)
        inside = (x >= self.xs[0]) & (x <= self.xs[-1])
        return ym, np.where(inside, th, 0.0)
```

"""Orientation simple (addendum P1 §1) : axe de construction, emplanture en z = 0, corde X, extrados +Y."""

from __future__ import annotations

from dataclasses import dataclass

import numpy as np
from build123d import Location, Plane, Solid

from aerorib.classify import Model
from aerorib.config import Config, OrientationAxis
from aerorib.midsurface import camber_offset
from aerorib.slicing import slice_layers, to_mesh


@dataclass(frozen=True)
class Orientation:
    location: Location
    axis: tuple[float, float, float]
    source: str


def choose_axis(model: Model, cfg: Config) -> tuple[np.ndarray, str]:
    if isinstance(cfg.orientation, OrientationAxis):
        v = np.asarray(cfg.orientation.axis, dtype=float)
        return v / np.linalg.norm(v), "axe forcé"
    spars = model.of("spar")
    if spars:
        return np.asarray(spars[0].spar.axis_dir, dtype=float), f"longeron {spars[0].body.name}"
    boxes = [s.body.solid.bounding_box() for s in model.of("skin")]
    lo = np.min([[b.min.X, b.min.Y, b.min.Z] for b in boxes], axis=0)
    hi = np.max([[b.max.X, b.max.Y, b.max.Z] for b in boxes], axis=0)
    axis = np.zeros(3)
    axis[int(np.argmax(hi - lo))] = 1.0
    return axis, "plus grande dimension"


def _section_area(mesh, axis: np.ndarray, t: float) -> tuple[float, np.ndarray | None]:
    section = mesh.section(plane_origin=axis * t, plane_normal=axis)
    if section is None:
        return 0.0, None
    planar, _ = section.to_2D()
    return float(sum(p.area for p in planar.polygons_full)), np.asarray(section.vertices)


def orientation_location(skin: Solid, axis: np.ndarray, tol: float = 0.02) -> Location:
    axis = np.asarray(axis, dtype=float)
    axis = axis / np.linalg.norm(axis)
    mesh = to_mesh(skin, tol)
    proj = mesh.vertices @ axis
    lo, hi = float(proj.min()), float(proj.max())
    inset = min(0.5, (hi - lo) / 4)
    a_lo, v_lo = _section_area(mesh, axis, lo + inset)
    a_hi, v_hi = _section_area(mesh, axis, hi - inset)
    root_is_lo = a_lo >= a_hi * 0.99
    z_dir = axis if root_is_lo else -axis
    root_t = lo if root_is_lo else hi
    verts = v_lo if root_is_lo else v_hi
    flat = verts - np.outer(verts @ axis, axis)
    centre = flat.mean(axis=0)
    te = flat[np.argmax(np.linalg.norm(flat - centre, axis=1))]
    le = flat[np.argmax(np.linalg.norm(flat - te, axis=1))]
    chord = te - le
    chord = chord - chord.dot(z_dir) * z_dir
    chord /= np.linalg.norm(chord)
    origin = centre + axis * root_t
    loc = Location(Plane(origin=tuple(origin), x_dir=tuple(chord), z_dir=tuple(z_dir))).inverse()
    (root,) = slice_layers(skin.moved(loc), [inset], tol)
    if root.polygons and camber_offset(max(root.polygons, key=lambda p: p.area)) < 0:
        loc = Location((0, 0, 0), (0, 0, 180)) * loc
    return loc


def orient(model: Model, cfg: Config) -> Orientation:
    axis, source = choose_axis(model, cfg)
    skin = model.of("skin")[0].body.solid
    loc = orientation_location(skin, axis, cfg.validation.tessellation_tol)
    return Orientation(loc, tuple(float(c) for c in axis), source)
```

"""Trous à relier à la peau : longerons (corps SPAR) et passages existants (addendum P1 §4)."""

from __future__ import annotations

import math
from dataclasses import dataclass

from build123d import Align, Box, Cylinder, GeomType, Location, Solid
from OCP.BRepAdaptor import BRepAdaptor_Surface
from OCP.TopAbs import TopAbs_REVERSED

from aerorib.classify import detect_spar
from aerorib.config import Config


class BoreError(ValueError):
    """Trou non pris en charge (message en français)."""


@dataclass(frozen=True)
class Bore:
    name: str
    x: float
    y: float
    radius: float
    sleeve: float
    strip: float
    side: int
    cut_hole: bool


def _side(slit_side: str) -> int:
    return 1 if slit_side == "top" else -1


def spar_bores(spars: list[tuple[str, Solid]], cfg: Config) -> list[Bore]:
    limit = math.cos(math.radians(cfg.passages.max_tilt_deg))
    out = []
    for name, solid in spars:
        info = detect_spar(solid)
        if info is None or abs(info.axis_dir[2]) < limit:
            raise BoreError(f"{name} : longeron non parallèle à l'axe d'impression (pris en charge en P5)")
        s = cfg.spar_settings(name)
        out.append(
            Bore(name, info.axis_point[0], info.axis_point[1], info.diameter / 2 + s.clearance,
                 s.sleeve, s.strip, _side(s.slit_side), True)
        )
    return out


def find_passages(skin: Solid, max_tilt_deg: float) -> list[tuple[float, float, float]]:
    limit = math.cos(math.radians(max_tilt_deg))
    found: list[tuple[float, float, float]] = []
    for face in skin.faces():
        if face.geom_type != GeomType.CYLINDER or face.wrapped.Orientation() != TopAbs_REVERSED:
            continue
        cyl = BRepAdaptor_Surface(face.wrapped).Cylinder()
        d = cyl.Axis().Direction()
        if abs(d.Z()) < limit:
            continue
        p = cyl.Axis().Location()
        key = (round(p.X(), 6), round(p.Y(), 6), round(cyl.Radius(), 6))
        if key not in found:
            found.append(key)
    return found


def passage_bores(skin: Solid, cfg: Config, exclude: list[Bore]) -> list[Bore]:
    p = cfg.passages
    if p.mode == "off":
        return []
    out = []
    for x, y, r in find_passages(skin, p.max_tilt_deg):
        if any(math.hypot(x - b.x, y - b.y) < 0.5 for b in exclude):
            continue
        out.append(Bore(f"passage {len(out) + 1}", x, y, r, p.sleeve, p.strip, _side(p.slit_side), False))
    return out


def bore_cut_tools(bores: list[Bore], bb, slit_width: float) -> list[Solid]:
    height = (bb.max.Z - bb.min.Z) + 20
    zc = (bb.max.Z + bb.min.Z) / 2
    reach = (bb.max.Y - bb.min.Y) + 20
    tools = []
    for b in bores:
        if b.cut_hole:
            tools.append(Cylinder(b.radius, height).moved(Location((b.x, b.y, zc))))
        align_y = Align.MIN if b.side > 0 else Align.MAX
        tools.append(
            Box(slit_width, reach, height, align=(Align.CENTER, align_y, Align.CENTER)).moved(Location((b.x, b.y, zc)))
        )
    return tools
```

"""Nervures en losange construites en 2D dans le plan de chaque plaque (addendum P1 §3)."""

from __future__ import annotations

import math

import numpy as np
from build123d import Face, Solid, Vector, Wire, extrude
from shapely import affinity
from shapely.geometry import Point, Polygon, box
from shapely.ops import unary_union

from aerorib.config import RibLayer
from aerorib.features.bores import Bore
from aerorib.midsurface import MidSurface

_FAR = 1e4


def bore_zones_2d(b: Bore, c: float, d0: float) -> list[Polygon]:
    r = b.radius + b.sleeve
    s0 = (b.x - c) / d0
    ellipse = affinity.scale(Point(s0, b.y).buffer(1.0, 32), r / abs(d0), r)
    half = (b.strip / 2) / abs(d0)
    band = box(s0 - half, min(b.y, b.y + _FAR * b.side), s0 + half, max(b.y, b.y + _FAR * b.side))
    return [ellipse, band]


def plate_profiles_2d(ss, ym, th, zones, *, gap, min_depth, ytop, ybot) -> list[tuple[bool, Polygon]]:
    deep = th > gap + 2 * min_depth
    if not deep.any():
        return []
    out = []
    for top in (True, False):
        far = ytop if top else ybot
        edge = np.where(deep, ym + (gap / 2 if top else -gap / 2), far)
        poly = Polygon(list(zip(ss, edge)) + [(ss[-1], far), (ss[0], far)]).buffer(0)
        if zones:
            shift = -_FAR if top else _FAR
            # ombre côté surface médiane : un fragment coincé entre la zone et la bande ne toucherait pas la peau
            shadow = unary_union([z.union(affinity.translate(z, yoff=shift)).convex_hull for z in zones])
            poly = poly.difference(shadow)
        for part in getattr(poly, "geoms", [poly]):
            if isinstance(part, Polygon) and not part.is_empty and part.area > 1e-3:
                out.append((top, part.simplify(0.01)))
    return out


def plate_solid(poly: Polygon, c: float, d0: float, d1: float, zmin: float, slit: float) -> Solid:
    def to3(s: float, y: float) -> Vector:
        return Vector(c + s * d0, y, zmin + s * d1)

    def ring(coords) -> Wire:
        return Wire.make_polygon([to3(*p) for p in list(coords)[:-1]], close=True)

    face = Face(ring(poly.exterior.coords), [ring(r.coords) for r in poly.interiors])
    return extrude(face, amount=slit / 2, dir=Vector(d1, 0, -d0), both=True)


def diamond_plates(
    bb, mid: MidSurface, bores: list[Bore], layer: RibLayer, *, angle_deg: float, gap: float, slit: float,
    min_depth: float,
) -> list[Solid]:
    ang = math.radians(angle_deg)
    zmin, zmax = bb.min.Z, bb.max.Z
    ytop, ybot = bb.max.Y + 5, bb.min.Y - 5
    length = (zmax - zmin) / math.cos(ang) + 10
    ss = np.linspace(-5, length, layer.samples)
    plates: list[Solid] = []
    for sign in (1, -1):
        d0, d1 = sign * math.sin(ang), math.cos(ang)
        reach = length * abs(d0)
        lo = bb.min.X - (reach if sign > 0 else 0) - layer.spacing
        hi = bb.max.X + (reach if sign < 0 else 0) + layer.spacing
        origin = bb.min.X + layer.phase
        for k in range(math.floor((lo - origin) / layer.spacing), math.ceil((hi - origin) / layer.spacing) + 1):
            c = origin + k * layer.spacing
            ym, th = mid.at(c + ss * d0, zmin + ss * d1)
            zones = [z for b in bores for z in bore_zones_2d(b, c, d0)]
            for _, poly in plate_profiles_2d(ss, ym, th, zones, gap=gap, min_depth=min_depth, ytop=ytop, ybot=ybot):
                plates.append(plate_solid(poly, c, d0, d1, zmin, slit))
    return plates
```

```python
"""Enchaînement P1 : orientation → surface médiane → outils → découpe → validation."""

from __future__ import annotations

from collections.abc import Callable
from dataclasses import dataclass

from build123d import Solid
from shapely.geometry import Point, Polygon

from aerorib.classify import Model
from aerorib.config import Config
from aerorib.features.bores import Bore, BoreError, bore_cut_tools, passage_bores, spar_bores
from aerorib.features.ribs import diamond_plates
from aerorib.midsurface import MidSurface
from aerorib.orient import Orientation, orient
from aerorib.slicing import slice_layers
from aerorib.validate import Report, validate


class PipelineError(ValueError):
    """Échec de génération (message en français)."""


@dataclass(frozen=True)
class BodyResult:
    name: str
    original: Solid
    result: Solid
    report: Report
    bores: tuple[Bore, ...]
    plates: int


@dataclass(frozen=True)
class RunResult:
    orientation: Orientation
    bodies: tuple[BodyResult, ...]

    @property
    def ok(self) -> bool:
        return all(b.report.ok for b in self.bodies)


def _spars_inside(skin: Solid, spars: list[tuple[str, Solid]], tol: float) -> list[tuple[str, Solid]]:
    bb = skin.bounding_box()
    (mid,) = slice_layers(skin, [(bb.min.Z + bb.max.Z) / 2], tol)
    envelope = [Polygon(p.exterior) for p in mid.polygons]
    kept = []
    for name, solid in spars:
        c = solid.bounding_box().center()
        if any(e.contains(Point(c.X, c.Y)) for e in envelope):
            kept.append((name, solid))
    return kept


def generate_skin(skin: Solid, spars: list[tuple[str, Solid]], cfg: Config) -> tuple[Solid, tuple[Bore, ...], int]:
    tol = cfg.validation.tessellation_tol
    bb = skin.bounding_box()
    nx, nz = cfg.split.grid
    mid = MidSurface.from_skin(skin, nx, nz, tol)
    try:
        bores = spar_bores(_spars_inside(skin, spars, tol), cfg)
    except BoreError as exc:
        raise PipelineError(str(exc)) from exc
    bores += passage_bores(skin, cfg, exclude=bores)
    plates = []
    for layer in cfg.rib_layers:
        plates += diamond_plates(
            bb, mid, bores, layer, angle_deg=cfg.rib_angle(layer), gap=cfg.split.gap,
            slit=cfg.slit_width, min_depth=cfg.split.min_rib_depth,
        )
    result = skin.cut(*plates, *bore_cut_tools(bores, bb, cfg.slit_width))
    solids = result.solids()
    if not result.is_valid or len(solids) != 1:
        raise PipelineError(f"découpe invalide ({len(solids)} solide(s), valide={result.is_valid})")
    return solids[0], tuple(bores), len(plates)


def run_model(model: Model, cfg: Config, progress: Callable[[str], None] = lambda m: None) -> RunResult:
    progress("orientation…")
    o = orient(model, cfg)
    progress(f"orientation : {o.source}")
    spars = [(s.body.name, s.body.solid.moved(o.location)) for s in model.of("spar")]
    bodies = []
    for s in model.of("skin"):
        skin = s.body.solid.moved(o.location)
        progress(f"{s.body.name} : surface médiane, trous et nervures…")
        result, bores, n = generate_skin(skin, spars, cfg)
        progress(f"{s.body.name} : {n} nervures, {len(bores)} trou(s) relié(s) — validation…")
        report = validate(result, cfg, original=skin)
        bodies.append(BodyResult(s.body.name, skin, result, report, bores, n))
    return RunResult(o, tuple(bodies))
```

"""Écriture des résultats : STEP, STL, rapport HTML."""

from __future__ import annotations

import re
from pathlib import Path

from build123d import export_stl

from aerorib.io_step import NamedBody, write_step
from aerorib.pipeline import RunResult
from aerorib.report import write_html


def safe_name(name: str) -> str:
    return re.sub(r"[^\w.-]", "_", name)


def export_results(run: RunResult, out_dir: Path, stem: str, formats: list[str]) -> list[Path]:
    out_dir = Path(out_dir)
    out_dir.mkdir(parents=True, exist_ok=True)
    single = len(run.bodies) == 1
    written: list[Path] = []
    if "step" in formats:
        written.append(write_step(out_dir / f"{stem}.step", [NamedBody((b.name,), b.result) for b in run.bodies]))
    for b in run.bodies:
        base = stem if single else f"{stem}-{safe_name(b.name)}"
        if "stl" in formats:
            path = out_dir / f"{base}.stl"
            export_stl(b.result, str(path), tolerance=0.02, angular_tolerance=0.3)
            written.append(path)
        written.append(write_html(b.report, out_dir / f"{base}-rapport.html", title=b.name))
    return written
