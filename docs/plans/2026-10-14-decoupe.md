# Découpe pour le volume d'impression, imprimantes, SBAR transversales — implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Checkbox steps.

**Goal :** choisir P1S/H2S ; chaque morceau rentre dans le volume (rotation sur plateau, puis coupes en Z, puis coupe plane dans la corde) ; STEP à plusieurs WING pris en charge ; SBAR transversales/inclinées ; découpes signalées et visibles dans l'aperçu.

**Spec :** `docs/specs/2026-10-14-decoupe-design.md` (autorité) ; cœur : `docs/specs/2026-10-09-aerorib-design.md`, `docs/specs/2026-10-11-servo-design.md`.

## Global Constraints
- Repère orienté : Z envergure (emplanture z = 0), X corde, Y épaisseur, extrados +Y.
- Vase mode : chaque couche = un seul contour sans trou ; la validation (`aerorib.validate`) est l'arbitre, chaque morceau est validé.
- **Aucune régression** : `fusion_aile_4412_simple_sbar_v2.step` ✔ 84 plaques ≈ 909 m (1 morceau, P1S) ; `aile_4412_servo_extrados.step` ✔ 111 plaques ; `aile_4412_double_sbar.step` ✔ ; `aile_rectangle_2sbar.step` ✔ ; tests Bambu tronçons ✔.
- Aperçu = génération (mêmes plans de découpe, mêmes plaques).
- Messages en français ; réglages validés (pydantic) ; défauts sûrs.
- Tests rapides sur géométrie synthétique (`aerorib.testing.synthetic`, à étendre : grande corde, flèche, dièdre, SBAR transversale) ; fixtures réelles en `slow`.
- Fixtures en lecture seule. Commits français + trailer. Jamais affaiblir un test. Un seul implémenteur à la fois.

### Task 1 : Imprimantes et gabarits
- `PRINTERS` += `h2s` (340, 320, 340). Gabarit par (printer, material) : `src/aerorib/templates/<printer>_<material>.3mf` (déjà déposés : p1s/h2s × pla_aero/asa_aero) ; résolution dans `config.resolve_template` (lire l'existant), `bambu.template` explicite prioritaire ; profils matière sans chemin de gabarit codé en dur pour l'imprimante.
- Volume utile = gabarit (aire imprimable + hauteur) − marge ; GUI : sélecteur imprimante (libellés « P1S (256 × 256 × 250) », « H2S (340 × 320 × 340) » selon les gabarits).
- Tests : chaque combinaison résout son gabarit ; H2S ⇒ volume 340×320×(340−marge) ; 3MF H2S écrit avec `printer_model` H2S ; PLA P1S inchangé (octets).
- Commit `feat(bambu): choix de l'imprimante P1S / H2S`.

### Task 2 : Placement sur le plateau (rotation)
- `layout.fit_on_bed(footprint_xy: Polygon, bed: (W, D), margin) -> Placement(angle_deg, fits, slack)` (calipers sur l'enveloppe convexe, angle de plus grande marge, 0° préféré si ça rentre).
- `bambu.write_project` : rotation autour de Z dans la transformation de l'objet (centrage conservé) ; rapport/CLI : rotation par morceau.
- Tests : rectangle 300×40 sur 256×256 ⇒ ~45° ; rentre droit ⇒ 0° ; ne rentre pas ⇒ fits False ; 3MF contient la rotation.
- Commit `feat(plateau): rotation automatique des morceaux`.

### Task 3 : Coupes en Z selon l'empreinte
- `plan_cuts` étendu (ou planificateur `plan_pieces`) : hauteur + empreinte (section maximale de chaque tronçon tournée) ; augmente n ; détecte « section isolée trop grande ⇒ corde nécessaire ».
- Tests synthétiques : aile en flèche qui rentre en hauteur mais pas en empreinte ⇒ +1 tronçon ; grande corde ⇒ signal « corde ».
- Commit `feat(troncons): coupes en Z selon l'empreinte sur le plateau`.

### Task 4 : Coupe plane dans la corde
- `features/chord_cut.py` (ou `segment.py`) : k minimal, plans suivant la corde i/k emplanture→saumon, inclinaison ≤ surplomb, évitement des longerons/gaines parallèles (+manchon+bande) et baies (+bande), erreur française si impossible.
- Pipeline : nervures sur la pièce entière puis coupe ; validation par morceau ; nommage T1-A… ; `segment.chord: auto|off` ; avertissement « découpe automatique … ».
- Tests : synthétique corde 400 sur P1S ⇒ 2 morceaux ✔ validés ; plan décalé hors d'un longeron ; inclinaison trop forte ⇒ erreur ; `chord: off` ⇒ erreur claire. Fixture réelle si une existe (sinon synthétique uniquement).
- Commit `feat(decoupe): coupe plane dans la corde`.

### Task 5 : Plusieurs corps WING
- `run_model` : n peaux ⇒ n morceaux, orientation commune, motif de nervures ancré sur la boîte globale, longerons/gaines/baies coupés par corps ; chaque morceau peut encore être découpé (avertissement).
- Tests synthétiques : aile coupée en 2 corps (en Z et en corde) ⇒ nervures alignées à la jonction (mêmes plans), chaque corps ✔.
- Commit `feat(pieces): STEP à plusieurs corps d'aile`.

### Task 6 : SBAR transversales / inclinées
- `features/bores.py` : axe quelconque ⇒ trou en goutte d'eau (pointe +Z, flancs au surplomb max), jeu ; débouchant si une extrémité sort par une face extérieure (peau, face de coupe, bout) sinon fente vers la peau la plus proche ; zones sans nervure (section du tube dans les plans de plaque, ombre) ; aperçu identique.
- Tests synthétiques : SBAR en corde traversant une coupe dans la corde ✔ ; SBAR inclinée 30° ✔ ; trou fermé ⇒ fente ; plafond du trou ≤ surplomb (mesure maillage).
- Commit `feat(longerons): SBAR transversales et inclinées`.
