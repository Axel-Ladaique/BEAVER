# Baies de servo et gaines de câble — implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Checkbox steps.

**Goal :** une aile STEP avec un corps `SERVO…` (baie, extrados ou intrados) et une gaine `SBAR…CABLE…` sort imprimable en vase mode : poche avec rampes et renfort, gaine allégée, nervures qui contournent la poche, emplanture côté gaine ; aperçu et GUI à jour.

**Spec :** `docs/specs/2026-10-11-servo-design.md` (autorité) ; cœur : `docs/specs/2026-10-09-aerorib-design.md`, `docs/specs/2026-10-10-p1-addendum.md`.

## Global Constraints
- Repère orienté : Z envergure (emplanture z = 0), X corde, Y épaisseur, extrados +Y.
- Vase mode : chaque couche = un seul contour sans trou ; toute paroi intérieure = deux bords d'une fente reliée à l'extérieur. La validation (`aerorib.validate`) est l'arbitre.
- **Aucune régression** : `tests/fixtures/fusion_aile_4412_simple_sbar_v2.step` reste ✔ 84 plaques / ≈ 909 m ; `aile_4412_simple_sbar_v3.step` ✔ ; `aile_4412_double_sbar.step` ✔ ; `aile_rectangle_2sbar.step` ✔.
- L'aperçu (`aerorib.preview`) produit exactement les mêmes plaques que la génération (même code de zones via `pipeline.rib_options`).
- Messages en français ; config validée (pydantic) avec erreurs françaises ; nouveaux réglages dans `Config` avec défauts sûrs.
- Tests rapides sur géométrie synthétique (`aerorib.testing.synthetic`) ; tests sur fixtures réelles marqués `slow`.
- Fixtures en lecture seule. Commits français + trailer. Ne jamais affaiblir un test.

### Task 1 : Noms fiables, rôle servo, gaines
- Signature par solide lue dans le texte STEP (nombre de faces + multiset des types de surfaces + rayons des cylindres arrondis à 0,01) comparée aux faces OCC du solide ; « nom ambigu » seulement si la signature ne départage pas. Test : `aile_4412_servo_extrados.step` → `SBAR_CABLES_SERVO` a Ø 11,5, `SBAR_2` Ø 12, `SBAR_14mm_1` Ø 14, sans avertissement d'ambiguïté (`slow` si > 20 s, sinon rapide).
- `Naming.servo = ["SERVO"]`, `Naming.cable_markers = ["CABLE"]` ; rôle `servo` ; un corps portant lui‑même un préfixe connu n'est jamais reclassé par le nom d'un parent. `Model` expose les servos ; `classify` marque les gaines (`SparInfo.cable: bool` ou rôle dérivé).
- `inspect` affiche `servo` et `gaine`.
- Tests : synthétiques (noms) + fixture servo : 1 peau, 2 longerons, 1 gaine, 1 servo.
- Commit `feat(classify): rôle servo, gaines de câble, noms fiables`.

### Task 2 : Emplanture automatique et réglable
- `OrientationConfig.root: Literal["auto","debut","fin"] = "auto"` (lire la structure existante de `orientation` dans `config.py`).
- `auto` : gaine touchant une extrémité de l'envergure (tolérance 0,5 mm) ⇒ emplanture de ce côté ; sinon règle actuelle. `Orientation.source` mentionne la raison.
- Tests synthétiques (gaine courte touchant chaque bout ; `debut` / `fin` forcés) + fixture servo : la gaine finit à z = 0 après orientation (`slow`).
- Commit `feat(orient): emplanture côté gaine et réglage debut/fin`.

### Task 3 : Gaine allégée
- `spars.cable` : `strip` (défaut = largeur de ligne du profil, ou valeur fixe 0,42 si plus simple), `slit_side`, `slit_width` hérité. Une gaine produit un `Bore(cut_hole=True, sleeve=0, anchor_gap=None/désactivé, …)` limité à l'étendue du corps.
- Rapport/CLI : « SBAR_CABLES_SERVO (gaine, Ø11,8) ».
- Tests synthétiques : gaine → trou + fente, pas d'attache ; validation ✔ sur une aile synthétique avec gaine.
- Commit `feat(gaines): gaine de câble allégée (trou + fente)`.

### Task 4 : Baie de servo (poche, rampes, zones de nervures)
- `features/servo.py` : `ServoBay` (nom, côté, boîte orientée, profondeur, Δ rampe), `servo_bays(model/servos, skin, mid, cfg)` avec les erreurs françaises de la spec ; `pocket_solid(bay, bb)` (boîte prolongée hors peau + rampes) ; `pocket_zones_2d(bay, c, d0, d1, zmin, zmax, strip)` (polygones dans le plan de plaque, même convention que `bore_zones_2d`).
- `generate_skin` : zones de poche dans les plaques (via `rib_options`), poche retirée avec les autres outils.
- Tests : synthétique (aile droite + boîte servo extrados puis intrados) ✔ imprimable, un seul contour par couche, rampes : aucune face de surplomb > max_overhang (mesure sur le maillage) ; erreurs : boîte ne traversant aucune peau, fond trop proche de la peau opposée. Fixture servo (`slow`) ✔ imprimable.
- Commit `feat(servo): baie de servo avec rampes et contournement des nervures`.

### Task 5 : Renfort de baie
- `servo.reinforce: bool = True`, `servo.reinforce_offset` (défaut = largeur de ligne), fente `slit_width` parallèle aux parois + fond + rampes, débouchant sur la peau ; incluse dans les zones de nervures.
- Tests : synthétique ✔ imprimable avec renfort ; la coupe à mi‑baie montre une fente supplémentaire de chaque côté (2 bouches de plus sur la peau d'ouverture) ; `reinforce: false` ⇒ pas de fente. Fixture servo ✔ (`slow`).
- Commit `feat(servo): renfort de baie par fente parallèle`.

### Task 6 : Aperçu, GUI, rapport, docs
- `preview` : poche + renfort dans la coupe et dans les zones (comptes = génération, test), vue de dessus : ouverture + rampes (`planform.baies`), gaines comme trous (type `gaine`).
- Frontend : libellés français des nouveaux réglages (`servo`, `orientation.root`, `spars.cable`), dessin des baies dans la vue de dessus, légende.
- Rapport HTML / CLI : baies listées. README : section « Baies de servo et gaines » (conventions de nommage, rampes, renfort, emplanture).
- e2e lent : fixture servo via l'API GUI → essai `ok`.
- Commit `feat(gui): baies de servo dans l'aperçu` + `docs: baies de servo`.
